# eth-phy

Modular Ethernet PHY driver stack for bare-metal Rust (`#![no_std]`, no allocations).

## Crates

| Crate | Description |
|-------|-------------|
| `eth-mdio-phy` | MDIO bus trait, PHY driver trait, IEEE 802.3 helpers |
| `eth-phy-lan87xx` | LAN8720A/8710A/8740A/8742A PHY driver |
